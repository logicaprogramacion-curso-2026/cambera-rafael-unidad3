# Taller 10: Implementación en Python de EduSync AI (Deber 7)

## Descripción del Proyecto
Este directorio contiene la implementación ejecutable en **Python** del sistema **EduSync AI: Automatización Docente Alineada a Estándares Internacionales de IA**, desarrollada a partir del pseudocódigo modelado en el Deber 6.

El programa simula el flujo de autenticación, ingesta de instrumentos de evaluación, análisis automatizado según cuatro ejes normativos internacionales, toma de decisiones por parte del docente y exportación del resultado.
